# 心跳联动 Android App

独立运行于小米 14 Pro。手机原生 BLE 接收 ECG-D01M01，复用 250 Hz 心搏检测算法，通过热点 UDP 转发至 ESP32、StickS3。网页、音乐和分析拍点均打包在 APK 内，不依赖 Mac 或互联网。

## 使用

1. 手机开启蓝牙和 `OmronHeartDemo` 的 2.4 GHz 热点，两块设备开机并接入热点。
2. 关闭 Mac 心电服务；退出 OMRON Plus 实时连接，避免争抢心电贴。
3. 打开「心跳联动」，点击「开始连接」，首次授权附近设备和通知。
4. 顶部显示「实时接收」以及 ESP32、StickS3 在线状态、回执数。
5. 音乐由用户点击播放；锁屏时音乐/网页动画可能暂停，原生前台服务继续转发数据。
6. 完成后点击「停止」。需要重新使用 OMRON Plus 时先停止本 App。

安卓系统不允许普通 App 静默开启已有的个人热点；可通过「热点设置」进入系统设置。小米省电策略可能结束后台服务，如发生请为本 App 设置无限制后台运行。App 不自动修改系统省电、安全设置。

## 构建

运行 `bash android/build.sh`。使用机器现有 Unity OpenJDK 17，以及 Google Android API 35 / Build Tools 35。APK 输出 `android/build/heartbeat.apk`。

公开版本使用演示配对参数；请同时修改两份 wireless.h 与 assets/token。APK 使用独立发布签名，不能直接覆盖本地原签名版本。签名私钥不随仓库发布。

无线协议沿用已部署固件：UDP 8766 接收 HELLO；回复到来源端口，消息含设备时间戳、递增序号。App 用本地持久化预留序号区间，避免重启被当作旧包。若来回切换 Mac/手机导致回执不增加，请重启两块接收板，以重置序号窗口。勿同时运行 Mac 和手机控制端。

心搏、信号质量及对拍为实验性可视化；对拍偏差不是扬声器输出延迟实测。
